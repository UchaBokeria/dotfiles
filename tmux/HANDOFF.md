## Goal
2026-11-08, Codex: warm Ctrl+A s on Blackwall and Arch with bounded caches, safe fallback and no disruption to live tmux work.

## State
Deployed and active on both machines. picker_service.py preloads the existing UI, maintains one read-only session/pane metadata snapshot and forks a separate worker for each popup. picker_client.c is compiled once per source change into a stable private runtime path; it passes the popup tty and receives a kernel pidfd over a same-UID Unix SOCK_SEQPACKET socket. No additional tmux client, session, window or pane is created by the helper. FirstPaint still publishes one complete centred/full-client frame, including the status row; Arch retains its rounded/capsule style.

Cache limits: 2 MiB metadata input / 1024 pane rows, no truncation (larger servers use fresh uncached queries). Per-popup preview retention is at most eight panes / 100,000 cells. Parent retains no preview contents; caches never write session metadata, previews or history to disk. At most four helper UI workers. One stable executable + checksum and two lock files live in mode-0700 /tmp/tmux-picker-UID; sockets are 0600. The checksum rebuilds corrupted binaries, atomic replacement preserves other live bindings, and stale sockets/build files are cleaned. No growing helper log.

Workspace JSON/tmux stay authoritative. Backend changes invalidate the snapshot; >350 ms snapshots refresh before use. Current session/window/pane and server generation are checked fresh. Existing live target validation/confirmation remains. A missing/unresponsive helper or build failure falls back to the ordinary picker; missing optional service code also leaves the backend working. No action is replayed after a worker has started. Parent-death signals, pidfds and socket monitoring prevent orphan workers or signalling a reused PID. Graceful helper replacement drains open pickers; tmux restart gets a fresh cache generation. Native layout and TMUX_PICKER_SERVICE=0 initialization retire the helper and retain regular bindings. Idle refresh is every two seconds, recent use every 300 ms.

Warm seven-open benchmark: Blackwall ~42 ms (previous ~94 ms), Arch ~32 ms (previous ~138 ms), with system-load variation. Actual idle helper RSS measured ~20 MiB / ~30 MiB respectively; current metadata 1449 bytes / 699 bytes. ## Gotchas
Blackwall ~/.config/tmux is not Git; canonical tracked copy is Arch ~/.config/.dotfiles/blackwall/tmux. Leave unrelated tmux.conf.local and status/opencode files untouched. Helper start requires no tmux restart: workspaces.py init installs/warms it; picker_service.py start refreshes a changed helper without rewriting status. source fingerprints retire outdated parents gracefully; existing popup workers finish. CLI status/retire select the current/default server. Runtime state paths are absolute and server/socket/PID generation checks prevent cross-server cache reuse; zombie server PIDs fall back to fresh discovery. The C transport uses Linux pidfds; unsupported/build-failure paths keep the regular Python picker. Never delete the stable executable while live bindings reference it.

Tests use disposable sockets. Native keyboard tests may need TMUX_TEST_KEY_DELAY=1 on busy Arch. Staging full CRUD/Resurrect tests needs plugins/tmux-resurrect and callbacks pointing at the staging scripts. Safety snapshots are in /tmp/tmux-picker-service-safety on each host. UI preferences remain in AGENTS.md and ~/.agents/AGENTS.md.

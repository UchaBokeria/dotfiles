## Gotchas
Blackwall directory is not Git; Arch branch nuc is the tracked deployment. Active config files are tmux.conf and tmux.conf.local, not dot-prefixed copies. Workspace IDs and origin mappings persist independently of Resurrect's layout snapshots; names identify restored sessions and rename hooks keep mappings current. Native tree ignores empty filters, so empty folders use a native menu instead. display-menu needs -- before disabled item labels. Native overlays must launch without holding the DB lock while waiting for input; naming popups schedule mutations after closing. send-keys -K targets the client for native ':' prompts; callbacks retain the caller pane explicitly. Native x/X remain destructive after their confirmation; D additionally protects attached sessions. Backups: /tmp/tmux-workspaces-backup-20261107 and /tmp/arch-tmux-workspaces-backup-20261107.

## Gotchas
Blackwall ~/.config/tmux is not Git. Arch canonical repo: ~/.config/.dotfiles/blackwall/tmux. Leave unrelated tmux.conf.local and status/opencode files untouched. Source only session-picker.conf if it changes; run workspaces.py init to install current binding. No live restart or session kills. Initial popup width/height and command arguments require run-shell -C format expansion; display-popup itself does not expand all arguments. Tmux list-keys filtering differs across versions; the opening test inspects the full key list. Test staging needs plugins/tmux-resurrect for the full workspaces.py suite; run that suite from the installed project. Native keyboard tests use fixed settling delays by default; TMUX_TEST_KEY_DELAY=1 accommodates a busy Arch host. Native fallback via layout --kind native remains supported.

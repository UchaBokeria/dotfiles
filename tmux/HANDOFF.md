## Goal
Persistent nested tmux workspaces with native sessions, separate local/global history, ordered shortcuts and exact focus/view restoration on Blackwall and Arch Linux.

## State
2026-11-07, Codex: deployed to both hosts. Prefix BTab switches between recent sessions inside the current workspace; prefix M-Tab switches the client's true global last session. Local history can seed from tmux attachment times on first use. Per-workspace current/last sessions, per-client global history, exact window/pane locations and detached focus persist atomically in ~/.local/state/tmux/workspaces.json (other sockets get separate files). Rename tracking updates all histories and focus. Resume restores exact focus on reconnect/startup and retries up to 30 seconds for Resurrect's target pane. Runtime identity uses boot ID, PID and process start time so a reused PID cannot confuse restored sessions.

Protected folders: General, Background, Archive. General starts at 1, and its shortcut follows row order when moved, per the user's final clarification (general_fixed=false). Root workspace shortcuts are 1-9, 0 (10), F1-F10 (11-20); Background defaults to pinned F11, editable with w -> p; Archive is pinned F12. Prefix shortcuts or plain keys in the picker select root workspaces; Alt+key selects children. Prefix s opens native sessions; s opens the hierarchical list, where J/K reorders the highlighted sibling without losing selection. w/prefix W manages CRUD. z archives/restores, m moves, C-r toggles Archive, h/l folds, H/L and Tab/BTab browse siblings, [/] parent/first child, ? full help.

Creation gives new ordinary workspaces a default shell. Empty views never refill automatically: w -> E confirms deletion of all member sessions, moves affected clients into safe General/Background sessions first, and keeps the server/folder alive. Empty workspaces display actions, including n to create a session. Removing a workspace confirms leaf-by-leaf and archives its sessions. Native x/X confirmations and Archive D purge protections remain. Permanent bulk deletion requests a new Resurrect save. Enter now activates the highlighted menu item (the conflicting Enter shortcut was removed), and Escape or empty names cancel curses naming popups.

b toggles a default-visible compact key guide above the native picker/preview; v toggles native preview. Both preferences survive restarts. Temporary pane-border settings restore on picker exit. Workspace filters update in native mode instead of closing/reopening it. Status uses existing theme colours and only b/? action hints; Arch uses rounded pills. Arch status/apply.sh and variant reapply the workspace wrapper after theme changes. Existing Resurrect/Continuum hooks/options are preserved; additive tmux hooks use index 9271.

Both isolated PTY suites passed on tmux 3.4 and 3.7c: CRUD and all delete confirmations, actual reordered numeric/nested shortcuts (including moving General to 2 then back), independent local/global history, menu Enter and Escape, empty folder retention, v/b persistence, native-mode continuity, pill formats, archive/move/purge, real Resurrect restart restoring exact session/window/pane, rename consistency, detach/reconnect and emptying all current sessions safely into Background. Default guide and native preview were visibly verified in terminal output. Live server PIDs remain 35471/3104; existing pane PIDs and client/window/pane targets were unchanged during deployment.

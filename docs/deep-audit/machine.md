Current wiki is versioned and defaults to development HEAD, so future changes must use installed-version documentation: [configuration notice](https://wiki.hypr.land/configuring/).
- **M-002 — Environment recovery must use live sockets.** This agent shell initially lacks user-bus variables and compositor signature. `/proc/2870/environ` also lacks the signature, likely because proc exposes startup environment rather than every later mutation. `hyprctl instances -j` supplies instance PID and Wayland socket and enables successful read-only queries. User systemd works with `/run/user/1000` and its bus address. Do not interpret an unconfigured shell's connection failure as a desktop outage.
- **M-003 — Theme deployment mixes symlinks and generated copies.** Most application configs link to the checkout; `~/.config/swaync` is an independent directory containing generated CSS and config. GTK3/4, Qt6ct and Kvantum also have generated local outputs. Reviewing only tracked paths misses the actual deployed styles. Root config comparison is ongoing.

Their process parent IDs are 1; autostart source and process ages must be reconciled before declaring which startup path launched them. `archpilotd`, browser bridge, mobile OpenCode, tunnels, sync and resource guard are active user services.

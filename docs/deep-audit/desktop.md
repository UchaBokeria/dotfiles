## Architecture and visual language

**D001 — Wallpaper is the shared colour input; derivation is centralized.** `wallust/wallust.toml:1-27` uses full backend, Lab space, dark palette and threshold 10, writing legacy consumer files plus one JSON handoff. `theme/blackwall_theme/palette.py:1-19` explicitly separates extraction (Wallust) from derivation (this package). The loader tries explicit palette, handoff, newest small Wallust cache JSON, eww SCSS and built-in fallback (`palette.py:159-180`). It deliberately skips cache files over 8192 bytes to avoid enormous raw-pixel Full files (`palette.py:119-138`). `theme/blackwall_theme/__main__.py:35-104` fans the same resolved tokens into Hyprland conf+Lua, Waybar, wlogout, GTK3/4, Thunar, Eww, Rofi, swaync, Mako, Cava, Kitty, Neovim, WhatsApp, Qt6ct/Kvantum, Spicetify and a marked tmux block. Some destinations are outside this repository. Parent pure-emitter comparison in `generated-comparison.json` found all 21 current generated targets exact text matches, including independently installed swaync; this is deployed text parity, not UI acceptance.

**D002 — Restrained liquid glass is an explicit source design, not inferred from the project name.** `theme/blackwall_theme/tokens.py:1-23` says background alpha must preserve solid text, rims must be inset, compositor and surface radii must agree, and depth should be shadows rather than colour. The actual scale is windows 22px, panels 18, controls 12, small marks 8, pill 999 (`tokens.py:255-262`); spacing 4/6/8/12/18 with a 20px gutter (`tokens.py:269-276`), body type Inter then SF Pro/Noto, monospace JetBrains/Meslo, and an explicit Symbols Nerd Font for icons (`tokens.py:284-312`). Motion is cubic-bezier(.32,.72,0,1), 150/220/320ms (`tokens.py:319-322`). Warning/error/success colours are fixed so wallpaper hue cannot erase their meanings (`tokens.py:34-43`). Foreground is corrected to 7:1 contrast against the opaque base, accent chroma/contrast gets fallback/brightening (`tokens.py:175-208`); these guarantees concern the base, not every real blurred background.

**D003 — Glass is two coordinated layers, not just transparency.** Panels paint their own alpha/gradient/rims; compositor namespace rules supply blur and ignore transparent pixels. `hypr/lua/rules.lua:10-36` defines the panel namespaces and thresholds; `hypr/lua/glass.lua:58-79` disables blanket window glass, enables live layer resampling capped at 30fps, and uses palette tint. The blackwall preset intentionally refracts the rim, while blackwall_panel increases frost/dimming and reduces refraction/dome to keep text stable (`glass.lua:81-138`). Only Kitty, Thunar and ArchPilot opt into window glass; video/image apps opt out (`glass.lua:159-170`). Waybar is deliberately absent from the plugin whitelist and remains on compositor blur (`glass.lua:148-159`). This is direct design commentary, not independent proof of Apple's implementation.

**D004 — Ordinary windows deliberately float.** Both `hypr/hyprland.conf:38` and `hypr/lua/settings.lua:34` choose dwindle as the fallback. `hypr/configs/windowrules.conf:104-121` and `hypr/lua/rules.lua:71-77` float/centre every new window at 1200×800, with comments saying "by request". Scrolling settings remain configured as a dormant alternative (half-screen columns, explicit thirds/halves/two-thirds/full, follow_min_visible=1); their presence does not mean scrolling is active. Keyboard movement uses Vim directions and arrows; ten normal workspaces plus magic and F1–F12 special workspaces provide multiple layers of spatial organization (`hypr/lua/keybinds.lua:59-115`). A passthrough submap preserves the full keyboard for VMs/remote desktops (`keybinds.lua:171-189`).

**D005 — The bar is a sparse interaction hub.** `waybar/config:1-27` puts workspace capsules left, media centrally, clock/audio/network/control centre right, on the top bottom layer with 7px breathing room. ArchPilot and swaync modules are defined and included but are not members of the configured right group (`waybar/modules/custom.jsonc:2-11`); definition is not visibility. Workspace modules are custom signal-9 renderers because the source records a Lua dispatcher mismatch in Waybar's native module (`waybar/modules/workspaces.json:1-14`). Audio polling exists only for the visible widget states where practical (`eww/state/ios.yuck:13-57`); network lists scan only on their drill-in view (`eww/state/net.yuck:19-62`).

**D006 — Information hierarchy and discoverable actions matter more than decoration.** Eww's source replaces unlabelled quick-action glyphs with labelled tiles (`eww/widgets/control_center/shortcuts.yuck:1-6`), replaces huge rings with 50px gauges and words rather than redundant CPU pictures (`sys.yuck:1-18`), and gives network rate a bidirectional history graph because it has no percentage (`sys.yuck:44-77`). Calendar has month/day/picker views; today ring, selection fill, plan dot and note dot keep meanings on separate channels (`eww/eww.scss:288-397`). Rofi's grid intentionally resembles Launchpad: full-screen scrim with no false panel edge, large icons, one pill search field; thumbnail grids use accent tint/rim selection rather than solid fill (`rofi/blackwall/grid.rasi:1-16,68-95`). Screenshots use wide previews and wallpaper library three-by-three previews (`rofi/blackwall/shots.rasi`, `wall.rasi`). These are source statements of design reasoning; owner preference should be corroborated in actual session history.

**D007 — Terminal/editor share wallpaper colours but preserve separate working ergonomics.** Kitty uses MesloLGS Nerd Font text with JetBrains Mono Nerd Font symbol-map ranges, 40% background opacity and full inactive text alpha (`kitty/kitty.conf:9-28,84-85`). Fish is the shell, remote control listens on an abstract Unix socket (`kitty.conf:100-105`), Ctrl+C copies only with a selection and otherwise interrupts (`kitty.conf:167-170`); Super+Shift+V calls the cloud smart-paste helper, preserving ordinary paste semantics (`kitty.conf:157-165`). Neovim's blackwall scheme maps semantic roles without spelling hex values, uses ANSI colours for syntax, and exports matching terminal colours (`nvim/colors/blackwall.lua:1-10,109-138,247-250`). Theme selection persists under stdpath(data), applies once at VimEnter, and the Telescope picker restores previews on teardown (`nvim/lua/custom/utils/themes.lua:3-76,113-117`). Other installed schemes are choices, not evidence of the active scheme. Neovim remains strongly Kickstart-derived with LSP/Mason, Telescope, Harpoon, DAP, formatter/linter, Strudel live coding and overlapping OpenCode integration (`nvim/init.lua`, `nvim/lua/custom/plugins/utilities.lua`).

**D020 — HyprMod override save and reload disagree.** `hyprmod/hyprmod/binds/override_state.py:154-182` emits all unbinds before all binds. `parse_saved_overrides` (`:193-231`) instead pairs one pending unbind with only the next bind and overwrites that pending slot on every new unbind.

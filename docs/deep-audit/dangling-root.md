# Unreachable Git content: root review

The initial `git fsck --full` returned 156 dangling commits, mostly WIP/stash merges, spanning 58 distinct trees. Ordinary merge diff-tree without explicit parent silently shows zero changes; explicit first-parent comparisons reveal the actual work. Metadata and content provenance are in dangling-commits.json, dangling-changes.json and dangling-blobs.json. First-parent changed blobs total316; whole-tree/untracked-stash-parent coverage remains a separate pending check. Do not treat these snapshots as accepted releases or direct owner instructions.

Root reviewed56 distinct changed blobs from scripts, docs, tmux, Fish and WhatsApp using fully read team current baselines plus every semantic delta. Six WhatsApp palette blobs are generated-classified after TOML/role/hex/16ANSI validation; stable warn/bad/good remain unchanged. Other wallpaper-derived color changes were structurally separated from semantic tmux differences. Retained review diffs omit complete credential-related lines; omitted generic comments are not claimed as secret review.

The progression supports a precise operational ideology: notification attention is a finite budget. Watch evolved from hourly unbounded repeats, to cooldowns, to three strikes, to mute/snooze, then to constant condition identities, severity ratchets and hysteresis. A failing probe is explicitly different from recovery. Migration rekeys old numeric conditions to avoid falsely alerting after deployment. The full current implementation also repairs transient recovery flaps without endlessly rewriting unchanged state.

Daemon ownership became more precise after 70 parked notification waiters were mistaken for the background watcher: detached action waiters gained their own --wait command identity, daemon matching gained its mode, NUL-separated /proc command lines were converted to spaces, and short-circuit grep pipelines were replaced because pipefail can turn SIGPIPE into false liveness failure. These are causal fixes rather than arbitrary style edits.

Quiet evolved from a two-second last-state poll into event monitoring plus periodic repair, child termination/death coupling, respawn/backoff, atomic serialized config updates and refusal to overwrite malformed live JSON. Timed mute replacement now stops stale timers, expiry rechecks under lock, reboot-lost transient timers are repaired, and transient services avoid forking out of their cgroup. Invalid inputs are rejected while a terminal still exists. Selftest evolved from leaving DND changed to saved state and EXIT/interrupt restoration; brightness was deliberately removed because even a passing test interrupted the owner.

Historical cheatsheet deltas show that exact notification anatomy was repeatedly corrected from observation: close buttons are hover revealers; selectors must traverse the actual parent node; minimum height belongs to content, not the card; controls share the spacing scale; critical uses glow rather than a muddy full wash. Early contradictory prose was superseded. These docs record prior tests/crashes, not current reproduction by this audit.

WhatsApp history specifically adds live file-theme reload, fallback polling underneath an adopted webhook, padded multirow cards, and matching hit-test/height geometry. Which-key tests changed from assuming Tab fit the first page to bounded paging; an older wait-until-scroll-stops test could loop because rendering clamps while the scroll state itself keeps increasing. Tmux stash variants precede today's native workspace picker, and one branch injects OpenCode context into all status variants; those are historical alternatives, not evidence the owner currently wants them active. Fish Bun completion history adds audit/dedupe/prune/repl/catalog/license/workspace switches; it is vendor CLI surface, not personal UX intent.

No source or service was modified; only audit artifacts were written. This is partial Git-object semantic closure, not a zero-new cycle.

## Stash full trees, including index/untracked parents

Root additionally read57 distinct versions in complete stash trees using the closest already-read version plus every delta; voice fixture metadata was inspected without playback. These establish important negative evidence: a former config watcher callback did nothing; a real hot-reload channel was added later. Socket existence became active dial liveness, stale socket removal and underlying polling. Notification selftest originally checked only a DND flag; later code checked actual critical-notification enforcement and restored owner state.

Installer lineage deliberately distinguishes repository package transactions from isolated AUR builds; headless reads and writes both get a session bus; detected answers reach headless execution; optional shell tooling is guarded; bootstrap tmux uses server environment and a long-lived session. SDDM Japanese aesthetic was made explicit after noticing it only lived in the root-owned installation. Submodule metadata pointing SDDM to this same dotfiles repo was replaced with real upstream; an unused network-manager submodule was removed. These are historical explanations corroborated by deltas, not fresh installation acceptance.

WhatsApp geometry evolves from inline timestamps and curved caps on multirow surfaces toward consistent separate transparent captions, even-width edges, padded content and matching click geometry. Root which-key moves from compressed columns with unreadable labels to scrollable single-row entries. This reinforces readability and stable structure as higher priorities than fitting everything on one screen. Palette hue differences alone remain generated state rather than new personal preferences.

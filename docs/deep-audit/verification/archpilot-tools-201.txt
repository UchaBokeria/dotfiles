## 1. Failure modes: untested and unhandled

### `context/terminal.py` — no tests at all
- **Stale double `active()` / mixed-window context (TOCTOU).** `summarize():90` calls `window_ctx.active()`, then `cwd_of_focused():83` calls `active()` *again*, then `scrollback(focused.pid):97` uses the pid from the *first* call. If focus changes mid-turn, cwd comes from window B and scrollback from window A. Fix would be to reuse one `ActiveWindow`.
- **Wrong-cwd from background children.** `_descendant_shell_cwd():34-53` BFS-returns the first childless descendant's cwd. A shell with a background `sleep` plus a foreground `nvim` returns whichever leaf BFS hits first, not the foreground process. No `/proc` foreground-group check.
- **PID reuse race.** `focused.pid` (`window.py:43`) is read, then `/proc/{pid}/cwd` is resolved later (`terminal.py:42`). A recycled pid yields another process's cwd. Unchecked.
- **Fence injection.** `summarize():98` wraps raw scrollback in ```` ``` ```` with no escaping. Terminal output containing ```` ``` ```` breaks the `<archpilot-context>` block and can inject prompt text. Same pattern in `clipboard.py:46`.
- **Unbounded chars.** `MAX_LINES = 120 (:25)` caps lines but not characters — 120 lines of minified JSON is a ~1 MB prompt injection. No char budget unlike `clipboard.py:14` (`MAX_CHARS = 4000`).
- **Silent conflation.** `scrollback():72-75` maps missing binary, bad socket, timeout, and `Error:` prefix all to `""`. The daemon cannot tell "kitty not installed" from "transient timeout". No `shutil.which` pre-check (contrast `system.py:16`, `triage.py:30`).

### `context/sessions.py`
- **`read()` second `stat()` is unguarded.** `_tail_entries():83-91` catches `OSError`, but `read():132` calls `path.stat().st_mtime` with no `try`. A transcript deleted/perm-changed between tail-read and stat raises `FileNotFoundError`/`PermissionError` out of `read():132`, and out of `index():145` (no try there either). Only missing *root* is tested (`test_sessions_index.py` "missing_root_is_not_fatal").
- **`stat()` inside sort key crashes whole index.** `index():144` runs `p.stat().st_mtime` as the sort key over *every* `*/*.jsonl`. One unreadable file aborts the entire session browser and `summarize()`. Untested.
- **Active-transcript truncation race.** `stat().st_size` at `:84`, then `seek(size - TAIL_BYTES)` at `:87`. If the file shrinks between (live writer), seek lands past EOF → silent `[]`. Tolerated but invisible.
- **Mtime-only liveness is spoofable.** `state` (`:43-49`) trusts `st_mtime`: backup/sync touching a file fakes `"working"`; future mtimes clamp to `"working"` via `age_s (:40-41)`. No handling.
- **Tail-cut progress lies.** `_todo_progress():105-117` only scans the last 64 KB (`TAIL_BYTES:19`). A session whose `TodoWrite` aged out of the tail reports `0/0` → `progress == "" (:58-61)`. Misleading, untested.

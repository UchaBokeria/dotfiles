# Telegram quick-actions menu (inline, bot-native)

`/menu` opens an inline-keyboard menu handled inside the telegram bot — buttons
edit the message in place (no message spam), respond instantly, and menu
navigation never touches Claude. Implemented as an idempotent patch to the
plugin's `server.ts`: `telegram/telegram-menu-patch.py`, auto-applied by
`telegram/claude-session.sh` on every start (backup: `server.ts.orig` on the
server). All the Telegram helper scripts (`tg-*.sh`, `set-effort.py`,
`transcribe.py`, `claude-session.sh`, `telegram-menu-patch.py`) live in
`telegram/` at the repo root.

Security: every callback payload is whitelisted against the button set before
use (`MENU_VALID`); sliced values are provably from the fixed set.

## Menu map
- **🧠 Model** Opus/Sonnet/Haiku/Fable → `tg-run.sh /model X confirm` (live)
- **⚡ Effort** Low/Med/High/Xhigh → `set-effort.py` (next new chat)
- **📊 Ops** → Health / Status / Diff / Logs▸ — run in-bot (`docker`/`git`/`uptime`), result posted
- **⚙️ Session** → Compact, Plan, Rename, Goal, Loop, Add-dir, cd, BTW
- **🛠 Do…** (tap → send text → Claude acts): Remember, Research, Fetch URL, Brainstorm, Ultraplan, Workflow, Design, Init

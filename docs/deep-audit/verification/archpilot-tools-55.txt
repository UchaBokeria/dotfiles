    blackwall: glass restyle across every surface, plus the unfinished panels
    
    Applies one design language to the whole rice and finishes the parts that
    were stubbed out.
    
    Theming
      - theme/blackwall_theme generates 17 surfaces from one token set: eww,
        waybar, rofi, mako, kitty, nvim, tmux, cava, GTK3/4, Qt6ct, Kvantum,
        wlogout, hypr and Spotify. Nothing spells a colour or radius literally.
      - Guard the accent for chroma. A greyscale wallpaper yielded an accent a
        shade off the background (contrast 1.05), making every selected state in
        the rice invisible. Colourless accents fall back; dim-but-coloured ones
        are brightened, keeping their hue.
      - setwall now checks wallust's exit status. It never did, so a wallpaper
        that wallust rejected changed the image while leaving the colours from
        the previous one. Walks the threshold down to 5, 2, 1 before giving up.
    
    Control centre
      - Network pane: wi-fi, ethernet, Tailscale and bluetooth, each row a
        control rather than a readout. Replaces four per-second nmcli polls with
        one 5s poll returning a single JSON blob.
      - Audio pane: the glyph is a mute button, the device name expands a picker,
        and switching a device moves playing streams onto it. Device enumeration
        reads pw-dump, because pactl cannot see this machine's only input (a
        loopback filter node).
      - Notification history, backed by a passive D-Bus monitor. mako's own
        buffer holds a handful of entries, carries no timestamps, and empties on
        every restart - which a re-theme causes.
      - The panel scrolls, so a section added later cannot push anything off the
        bottom of the screen.
    
    Calendar
      - Replaces the bare GTK calendar widget, which offers no hook to style
        today apart from the selected day and no way to mark dates carrying
        data. Per-date reminders, world clocks, and a tier-1 notification for
        what is unfinished today.
    
    Tooling
      - blackwall-shot/-shots: capture with OCR, translation, ArchPilot and a
        rofi history browser. Everything lands on the clipboard and on disk.
      - blackwall-clip, -clean, -watch, -snapshot, -net, -audio, -cal, -notify.
      - 10 background checks across 3 tiers. None of them can run a root command:
        a cleanup triggered from a notification must not ask for a password.
    
    Fixes found along the way
      - cliphist recorded nothing because no watcher was ever started.
      - mako started twice, from exec.conf and dbus activation.
      - 8 keybinds pointed at files that did not exist, including a gpu-switch on
        a machine with one GPU.
      - setwall and rofi-paper were copied into /usr/bin rather than linked, so
        edits here had no effect on what ran.
      - Styling a button in eww.scss never reaches its label: `* { color: $fg }`
        sets the value directly, and a directly-set value beats an inherited one.
    
    Wallpapers renamed for their contents; names encoding a palette rather than a
    picture were left alone. 74 tests over the token system.

    feat: installer questions, opencode in the rice, flameshot and clipboard fixes
    
    Makes a fresh clone of this branch actually reproducible, and fixes four
    things on this machine that were quietly broken.
    
    Installer
    - Ask what cannot be detected: a new questions screen (installer/data/
      questions.toml) covering the modifier key every binding hangs off, the
      VA-API driver, whether to update the system first, and the login shell.
      Answers are exported to every step as environment variables.
    - Write hypr/lua/machine.lua from those answers. hyprland.lua defines a
      BLACKWALL table of defaults and pcall-requires "machine", so the per-machine
      keybind file that used to be hand-edited and lost on every clone now travels
      with the install. machine.lua.example documents it.
    - Update the system before packages (`first = true` steps run above the
      package groups): `pacman -Sy` followed by `-S` is how a partial upgrade
      happens.
    - Backups no longer overwrite the thing they save. expand("~") returned a
      literal "~", so stripping the home prefix failed and backup.join(<absolute>)
      discarded the backup root: the rename was a no-op onto the original, which
      cp -a then overwrote. Backups outside home keep their shape under the root,
      and a path that would land on its target is refused.
    - `--restore` is now the whole undo: files the run created are recorded in
      .blackwall-created and removed again, but only where they are still exactly
      what the installer left. scripts/blackwall-undo does the same in bash, so
      undo works on a machine where the build does not.

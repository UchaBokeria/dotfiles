reports the status of the `set -q` that opened the line, not of the branch that
actually ran. So `fish-universals` was marked FAILED on every fresh install

the same shape.

set -q BBB; set -Ux BBB 8; end` exits 0 with BBB=8, and exits 0 again when BBB
is already there. All five lines use the if form now.

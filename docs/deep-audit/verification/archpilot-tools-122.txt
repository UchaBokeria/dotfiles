## 9. CLI (`archpilot …`) and socket protocol

| Command | Does |
|---|---|
| `ui [--toggle]` | open or focus the window; `--toggle` closes it if open |
| `toggle` | alias of `ui --toggle` |
| `send TEXT… [--mode] [--model] [--session] [--new]` | send a prompt |
| `state` | print the daemon's state snapshot as JSON |
| `subscribe [--eww] [--once] [--retry S]` | stream events (general tap) |
| `approve [ID] [--deny]` | answer the pending approval (empty id means the only one waiting) |
| `password [VALUE]` | answer a sudo prompt (prefer stdin) |
| `set engine\|mode\|model\|effort [VALUE] [--cycle]` | change the live session |
| `new` / `cancel [--session]` | new chat / stop the running turn |
| `run [N]` / `copy [answer\|prompt\|action] [N]` | run or copy suggested action N |
| `shot [--file PATH]` | region grab (or an existing image), staged for the next prompt |
| `history [--json\|--print] [--limit]` | rofi picker over past prompts (the daemon runs rofi) |
| `sessions [--json\|--print]` | rofi picker over Claude sessions; opens `kitty -- claude --resume` |
| `scroll up\|down\|page-up\|page-down\|top\|bottom` | eww-era viewport scroll |
| `triage [--notify\|--json\|--ask KEY]` | ambient checks; `--ask` seeds a new chat with the fix prompt |
| `waybar [--watch]` | waybar custom-module JSON |
| `undo` | `git revert` the newest `archpilot:` commit |

**Protocol** (`ipc.py`): one JSON object per line over
`$XDG_RUNTIME_DIR/archpilot.sock`, with `/tmp/archpilot-<uid>/` as a fallback.

- Client ops:
  - `prompt`, `subscribe`, `state`, `approve`, `password`, `toggle`,
    `cancel`, `new`.
  - `tab` {new|next|prev|close|select, index}.
  - `draft`, `rewind` {index}, `picker` {history|sessions}, `scroll`.
  - `widget` {hide|show}.
  - `set` {field engine|mode|model|effort|mcp, value, cycle, enable}.
  - `run_action` {index}, `attach` {paths}, `detach` {path}.
  - `open_session` {session_id, cwd}, `rename` {session_id, title}.
  - `ask_permission` (hook only), `ask_password` (askpass only).
- Events from the daemon: `state` (the full snapshot, `Session.snapshot()`
  plus pending/password/draft/tabs/attachments/model_choices), `delta`,
  `turn_end`, `approval_request`, `password_request`, `error`,
  `restore_input`.
- The snapshot is intentionally flat. It still carries eww-era fields
  (`transcript`, `answer_markup`, `action0..2`); the GTK UI uses `turns`.

## 16. Ambient triage

`archpilot-triage.timer` fires 10 minutes after login, then every 6 hours. It
runs `archpilot triage --notify`, which scans four checks:

- `pacnew`: `.pacnew`/`.pacsave` files under `/etc`.
- `failed-units`: failed units, system and user; urgent.
- `disk`: a filesystem ≥90 % full, urgent at ≥95 %.
- `docker`: ≥5 GB reclaimable.

An unchanged finding is re-notified only after 12 hours. Each finding carries
a ready prompt, so `archpilot triage --ask <key>` starts a new chat with it.
Those generated prompts are filtered out of history. The rice's
`blackwall-watch` runs its own, overlapping checks; the two are independent.

### Schedule Periodic Background Write Task with WorkManager (Kotlin)

Source: https://developer.android.com/health-and-fitness/health-connect/write-data

Use this snippet to schedule periodic background tasks for writing data to Health Connect. It configures a WorkManager request to run every 15 minutes with a 5-minute flex interval, only when the device is idle and not low on battery.

```kotlin
val constraints = Constraints.Builder()
    .requiresBatteryNotLow()
    .requiresDeviceIdle(true)
    .build()

val writeDataWork = PeriodicWorkRequestBuilder<WriteDataToHealthConnectWorker>(
        15,
        TimeUnit.MINUTES,
        5,
        TimeUnit.MINUTES
    )
    .setConstraints(constraints)
    .build()
```

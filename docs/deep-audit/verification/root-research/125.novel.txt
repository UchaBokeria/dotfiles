### Display images with AsyncImage

Source: https://coil-kt.github.io/coil/changelog

Use AsyncImage to load images from the network in Jetpack Compose. The second example demonstrates advanced configuration including placeholders, cropping, and animations.

```kotlin
// Display an image from the network.
AsyncImage(
    model = "https://example.com/image.jpg",
    contentDescription = null,
)

// Display an image from the network with a placeholder, circle crop, and crossfade animation.
AsyncImage(
    model = ImageRequest.Builder(LocalContext.current)
        .data("https://example.com/image.jpg")
        .crossfade(true)
        .build(),
    placeholder = painterResource(R.drawable.placeholder),
    contentDescription = stringResource(R.string.description),
    contentScale = ContentScale.Crop,
    modifier = Modifier.clip(CircleShape)
)
```

### AsyncImage Usage Examples

Source: https://coil-kt.github.io/coil/changelog

Demonstrates various ways to implement AsyncImage, including basic loading, custom state handling, and modifier application.

```kotlin
// Only draw the image.
AsyncImage(
    model = "https://example.com/image.jpg",
    contentDescription = null, // Avoid `null` and set this to a localized string if possible.
)
```

```kotlin
// Draw the image with a circle crop, crossfade, and overwrite the `loading` state.
AsyncImage(
    model = ImageRequest.Builder(LocalContext.current)
        .data("https://example.com/image.jpg")
        .crossfade(true)
        .build(),
    contentDescription = null,
    modifier = Modifier
        .clip(CircleShape),
    loading = {
        CircularProgressIndicator()
    },
    contentScale = ContentScale.Crop
)
```

```kotlin
// Draw the image with a circle crop, crossfade, and overwrite all states.
AsyncImage(
    model = ImageRequest.Builder(LocalContext.current)
        .data("https://example.com/image.jpg")
        .crossfade(true)
        .build(),
    contentDescription = null,
    modifier = Modifier
        .clip(CircleShape),
    contentScale = ContentScale.Crop
) { state ->
    if (state is AsyncImagePainter.State.Loading) {
        CircularProgressIndicator()
    } else {
        AsyncImageContent() // Draws the image.
    }
}
```

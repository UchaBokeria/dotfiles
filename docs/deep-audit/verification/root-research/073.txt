### Android > Android APK size (shared object compression)

Source: https://docs.flutter.dev/platform-integration/legacy-ffi-plugin.md

Android guidelines recommend distributing native shared objects uncompressed so they can be loaded directly from the APK without extracting them to temporary storage, saving on-device space. By default, Flutter compresses native libraries like libflutter.so and libapp.so to minimize APK download size at the expense of larger on-device size. Native library compression and extraction behavior at install time can be configured using the Android Gradle plugin's useLegacyPackaging option.

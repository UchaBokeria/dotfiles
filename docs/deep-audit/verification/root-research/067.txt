### Java 11+ APIs available through desugaring

Source: https://developer.android.com/studio/write/java11-default-support-table

Java 11 support API desugaring comes in three flavors: minimal, default, and nio. The minimal version includes the java.util.function package and replacement classes for some Android framework concurrent collections. The default version, an upgrade from Java 8 API desugaring, includes java.time and java.util.stream packages in addition to the minimal version. The nio version includes the java.nio package in addition to everything in the default version.

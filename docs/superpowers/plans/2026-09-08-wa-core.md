# wa Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `wa`, a vim-driven terminal WhatsApp client in Go that reads and sends text through `wacli`, with a configurable keymap, a blackwall-derived theme, and a full modal editing engine.

**Architecture:** Reads go directly to wacli's WAL-mode SQLite store through a read-only connection guarded by a schema-version probe, falling back to `wacli --json` when the schema is unrecognized. Every write goes through the `wacli` CLI, which owns the store lock and delegates sends to a long-lived `sync --follow` process that `wa` adopts or spawns. The UI is Bubble Tea; the vim engine is a standalone package that knows nothing about WhatsApp and emits action names that a registry resolves.

**Tech Stack:** Go (CGO_ENABLED=0), `modernc.org/sqlite`, `github.com/charmbracelet/bubbletea`, `github.com/charmbracelet/lipgloss`, `github.com/BurntSushi/toml`, `github.com/fsnotify/fsnotify`, `golang.org/x/crypto/argon2`, `github.com/charmbracelet/x/exp/teatest`.

**Spec:** `docs/superpowers/specs/2026-09-08-wa-core-design.md`

## Global Constraints

- Module path: `github.com/UchaBokeria/blackwall/whatsapp`. Root: `blackwall/whatsapp/`. Binary: `wa`.
- `CGO_ENABLED=0` everywhere. No dependency may require cgo. This rules out `mattn/go-sqlite3`.
- `go.mod` declares `go 1.22` so Ubuntu's packaged toolchain can build it. Do not use language features newer than 1.22.
- No colour literal in any `.go` file. Colours come only from `internal/theme`, which loads `whatsapp/theme.toml` or the embedded fallback.
- `internal/vim` imports nothing from `internal/domain`, `internal/store`, `internal/wacli`, or `internal/ui`. It is WhatsApp-agnostic.
- `internal/store` never writes. `internal/wacli` is the only package that calls `os/exec`.
- Tests never touch `~/.local/state/wacli`, never spawn a real `wacli`, and never contact the network.
- Defaults mirroring the author's Neovim config, exact values: `leader = "<Space>"`, `timeoutlen = 300`, `scrolloff = 10`, `ignorecase = true`, `smartcase = true`, `clipboard = "unnamedplus"`, `gutter = "hybrid"`.
- Every degradation (schema fallback, poll fallback, missing tool) is announced once in the status line and recorded in the `:log` buffer. Nothing fails silently.
- Commit after every task. Conventional Commits prefixes (`feat:`, `fix:`, `test:`, `docs:`, `chore:`).

```python
"""wa - WhatsApp TUI palette, TOML."""


def watui(t) -> str:
    lines = [
        "# blackwall design tokens - generated, do not edit",
        "# edit theme/blackwall_theme/tokens.py and run `blackwall-theme` instead",
        "",
    ]
    for name in ("bg", "fg", "accent", "on_accent", "link", "muted", "faint",
                 "cursor", "raised", "raised_hi", "sunken", "edge", "selection",
                 "warn", "bad", "good"):
        lines.append(f'{name} = "{getattr(t, name).hex6}"')
    lines.append("")
    lines.append("ansi = [")
    for i in range(16):
        lines.append(f'  "{t.ansi[i].hex6}",')
    lines.append("]")
    return "\n".join(lines) + "\n"
```
